# Prompt Improver Skill (thin Claude adapter)

정본이 아니다. 규칙은 여기 복제하지 않는다.

하네스 프롬프트를 개선하기 전에:

1. [AGENTS.md](../../../AGENTS.md)를 읽는다.
2. 정본 [agents/prompt-improver/AGENTS.md](../../../agents/prompt-improver/AGENTS.md)를 읽는다.
3. 영향받는 정본 파일을 읽는다.
4. adapter-specific 이슈가 아니면 어댑터 파일을 수정하지 않는다.
5. 먼저 Proposal을 만든다. 명시 승인 후에만 정본을 고친다.
