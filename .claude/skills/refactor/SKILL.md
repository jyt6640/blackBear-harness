# Refactor 역할 런처 (얇은 어댑터)

정본은 [agents/refactor/AGENTS.md](../../../agents/refactor/AGENTS.md)다. 규칙은 여기 복제하지 않는다.

1. 정본 [agents/refactor/AGENTS.md](../../../agents/refactor/AGENTS.md)를 읽는다.
2. 입력: `02-green-implementation-report.md`.
3. 출력: `03-refactor-report.md` ([templates/03-refactor-report.md](../../../templates/03-refactor-report.md)). 개선이 없으면 "개선 사항 없음 + 행위 보존 확인"을 기록한다.
4. 단계가 끝나면 멈추고 다음 단계(/review)를 요청한다.
