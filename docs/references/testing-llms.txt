# testing-llms.txt

목적: LLM 역할 에이전트가 참조하는 테스트(JUnit5 / Mockito) 압축 레퍼런스.
정본 규칙이 아니다(테스트 철학은 docs/principles, agents/test). 사실 확인용 인덱스다.
버전 핀: JUnit 5.x / Mockito 5.x. 갱신 시 이 헤더의 버전을 바꾼다.

## 권위 있는 출처

- JUnit 5 User Guide: https://junit.org/junit5/docs/current/user-guide/
- Mockito: https://javadoc.io/doc/org.mockito/mockito-core/latest/org/mockito/Mockito.html

## 자주 쓰는 사실 (채워 나간다)

- 테스트 단위는 production class의 public behavior. private는 직접 테스트하지 않는다.
- 더블 선택은 책임 기준: Service=Mock(협력 호출), Validator=Fake 우선(상태 검증).
- 동시성 검증은 실제 Spring Context + DB 통합 테스트로.

> 이 파일은 시작 스텁이다. 실제 작업에서 반복 참조되는 항목만 추가한다(과확장 금지).
